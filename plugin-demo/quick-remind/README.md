# 闪电提醒 · 一句话倒计时与提醒看板 (`quick-remind`)

Lucent 官方自然语言提醒插件（Plugin v3.7 · 原生 Swift 6 `arm64` 可执行程序 `bin/quick-remind`，零 Python 运行时依赖）：

- **一句话秒建提醒**：支持 `10m 喝水`、`1.5h 开会`、`18:30 拿快递`、`明天 9:00 交周报 工作日`、`in 25 min stretch` 等中英文自然表达，以及一键开启 25 分钟番茄钟。
- **零常驻守护进程触发**：严守无后台守护进程原则，自动将提醒安全写入 macOS 原生「提醒事项 (Reminders.app)」准点弹窗通知，同时维护本地待办看板、推迟（Snooze）、周期重复推进与语音播报。
