# Antigravity Pulse · 用量统计与额度监控 (`antigravity-pulse`)

基于 **原生 Swift (`PluginKit` + `AppKit` + `SQLite3` + `WKWebView` 离线自由窗口)** 编译为 `arm64` 可执行文件（`bin/antigravity-pulse`，零网络权限、零 `launchd` 常驻进程、绝不修改 Antigravity 客户端本体），通过双层增量索引（近期逐轮热缓存 + 全历史按日冷归档）与 Antigravity CLI 官方 `statusLine` 回调，提供 **缩边监控悬浮窗 + 独立可缩放全景统计大窗** 双窗协同体验。

## 核心特性

- **独立可缩放全景统计大窗（`agstat` / 悬浮窗顶栏一键打开）**：原生 macOS 标准窗口（默认 `1100 × 760`，支持任意缩放与浅/暗双外观联动），与缩边悬浮窗并存、互不干扰，提供 `今日 / 7天 / 30天 / 90天 / 全年 / 全部` 周期切换、`$ USD / ¥ CNY` 一键币种切换、**一键生成 `@2x` Retina 精美分享海报并复制到剪贴板**（支持「曜石暗夜 / 晴霜白瓷 / 极光深蓝」三套画风、隐私脱敏与保存到桌面）以及 Markdown / CSV 报表导出。
- **GitHub 风格 52 周每日 Token 贡献热力图**：默认按**含缓存总处理量（M）** 5 级翡翠绿分位着色，支持一键切换「净用量 (M) / 估算金额 / 对话轮次」；鼠标悬浮展示当日详细 Breakdown，点击任意日期展开**当日模型与会话下钻抽屉**并一键「直达↗」原对话；底部实时汇总连续活跃天数（Streak）、日均 M 与峰值日。
- **多维深度分析与全量会话浏览器**：HiDPI Canvas 2D 每日/每周堆叠趋势图、24 小时活跃节律分布、分模型消耗与缓存节省排行（附透明 API 参考价目表）、项目/工作区消耗排行（点击联动过滤），以及支持搜索/筛选/排序/直达的全量会话明细表。
- **官方 `statusLine` 自动实时额度（共享/本机独享可控）**：通过 Antigravity CLI 官方公开 `statusLine` 钩子（保留原状态栏 `stack_with_default: true`，并自动兼容读取 `~/.config/ai-audit/agy-quota.json`）自动显示官方 5h / 7d 实时剩余百分比、重置倒计时与多模型配额组。**默认处于「共享额度」模式**（因 AGY 额度为账号多设备共享，仅客观统计本机窗口消耗、不做满额反推）；若确认该账号仅本机使用，可一键切换为 **「本机独享」** 自动开启 5h / 7 天 / 月度 100% 全额度价值推算。
- **缩边停靠 · 悬停自动展开悬浮窗**：平时以精简耳标紧贴屏幕边缘不挡视野，悬停展开大悬浮窗，滚轮切换活跃项目，内置一键直达对应对话（标准 macOS Accessibility）与掉缓存 / 会话完成系统提醒。

## 安装方式

1. **通过插件市场一键安装**：打开 **Lucent → 设置 → 插件中心 → 精选市场**，在官方商店列表中点击 `Antigravity Pulse · 用量统计与额度监控` 右侧的 **「一键安装」**。
2. **命令行快捷安装**：`bash plugin-demo/install.sh antigravity-pulse`
