# Antigravity Pulse · 上下文与会话监控 (`antigravity-pulse`)

基于 **原生 Swift (`PluginKit` + `AppKit` + `SQLite3` + `WKWebView` 自由画布)** 编译为 `arm64` 可执行文件（`bin/antigravity-pulse`，零网络权限、零 `launchd` 常驻进程、绝不修改 Antigravity 客户端本体），通过只读读取 `conversation_summaries.db` 与增量扫描 `transcript.jsonl`，提供**缩边自动展开大窗**的简洁 iOS 风格悬浮窗（默认 `showInDock: false` 不占程序坞，始终置顶）。

## 核心特性

- **缩边停靠 · 悬停自动展开完整大悬浮窗**：平时以超精简耳标（`136 × 74` 侧边 / `228 × 44` 顶边）紧贴屏幕边缘不挡视野；鼠标移上去自动丝滑展开为完整大悬浮窗（`352 × 334`），鼠标移开后自动优雅缩回边缘；拖离边缘可随时变为常驻大窗，拖回边缘再次缩边。
- **鼠标滚轮瞬时切换相邻活跃项目**：无论缩边耳标还是展开大窗，滚动鼠标滚轮（或按方向键）即可在活跃项目间切换，运行中的项目自动排在最前面，顶栏直接展示 `[项目名] 对话标题` 与序号。
- **一键直达对应对话（零侵入标准 macOS Accessibility）**：点击「直达↗」通过系统标准辅助功能接口定位侧边栏对应对话 `UUID` 并直接切换，不再误创空白新对话（CLI 会话则一键复制 `agy --conversation <id>`）。
- **清晰净用量与双段上下文监控**：上下文双段进度条直观区分「缓存读取 + 新输入」，支持 `累计 / 本轮` 缓存命中率与 `5h / 今 / 7d` **净用量（新输入 + 输出）**，附带含缓存总量与掉缓存/会话完成提醒。

## 安装方式

1. **通过插件市场一键安装**：打开 **Lucent → 设置 → 插件中心 → 精选市场**，在官方商店列表中点击 `Antigravity Pulse · 上下文与会话监控` 右侧的 **「一键安装」**。
2. **命令行快捷安装**：`bash plugin-demo/install.sh antigravity-pulse`
