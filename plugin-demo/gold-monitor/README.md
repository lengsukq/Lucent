# 黄金大盘悬浮窗 · Au99.99 (`gold-monitor`)

基于 **原生 Swift (`PluginKit` + `AppKit` + `WKWebView` 自由画布)** 编译为 `arm64` 可执行文件（`bin/gold-monitor`，零后台常驻进程），实时监控上海黄金交易所 **Au99.99** 与 **Au(T+D)** 人民币元/克行情，并提供平滑变形的三形态桌面置顶悬浮窗（默认 `showInDock: false`，不占程序坞）。

## 核心特性

- **三形态丝滑原生变形**：支持 **标准分时图卡片**、**Mini 极简悬浮条** 与 **靠边超精简挂件**（拖近屏幕左 / 右 / 顶边缘自动磁吸停靠，悬停平滑展开），单窗口原地过渡零闪烁。
- **实时行情与日内分时折线**：整合新浪财经实时现货报价与东财 / 华尔街见闻日内分时曲线，自动合并盘中实时 tick 并在离线时优雅回落至最近缓存报价。
- **双层防抖价格预警**：支持在悬浮窗内直接设置突破上限 / 跌破下限预警价与冷却时间，附带滞回区间防止临界抖动重复推送，通过 Lucent Host Bridge 投递原生 macOS 系统通知。
- **可自定义配色与主题**：支持中式（红涨绿跌）/ 国际（绿涨红跌）配色及纯白玻璃 / 浅香槟金 / 跟随系统三种外观。

## 安装方式

1. **通过插件市场订阅 `plugin-demo` 商店一键安装**：打开 **Lucent → 设置 → 插件中心 → 精选市场**，在商店列表中点击 `黄金大盘悬浮窗 · Au99.99` 右侧的 **「一键安装」**。
2. **命令行快捷安装**：`bash plugin-demo/install.sh gold-monitor`
