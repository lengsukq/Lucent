# 窗口分屏与工作区 (`window-snap`)

纯原生 Swift 6 + 液态玻璃无边框悬浮控制台，为 Lucent 补齐 **窗口分屏** 与 **多屏工作区布局一键恢复**，零后台常驻进程、零外部依赖。

## 核心能力

- **全场景窗口分屏与跨屏瞬移**：支持左/右/上/下半屏、左/中/右三分之一、左/右三分之二、四象限、最大化、黄金居中（72%×80%）、几乎满屏（90%）、移至上/下一块显示器，以及一键撤销上次分屏（`restore`）。
- **多屏工作区快照与一键恢复**：一键捕获当前全部显示器上的应用窗口排版（按相对比例与显示器 ID 归一化记录）；外接显示器分辨率变化或断开时自动比例适配/折叠至主屏，支持自动启动未打开的应用、设为常用及同步至 `⌥Space` 免前缀全局秒搜。
- **不抢焦点的液态玻璃浮窗**：采用 `.nonactivatingPanel` 悬浮控制台，点击任意分屏格即可直接排列当前前台应用窗口，支持贴边收起为极简胶囊、晴霜浅色/曜石暗色双主题实时切换与中英双语。
- **最小权限安全边界**：仅声明 `capabilities: ["floatingWindow", "windowControl"]`、`resourceScopes: []`，由 Lucent 宿主统一代申并管控 macOS 辅助功能（Accessibility）权限。

## 快捷使用

1. 在 **Lucent › 设置 › 插件中心 › 窗口分屏与工作区** 中为常用分屏动作（如左半屏、右半屏、最大化、移到下一屏）录制全局快捷键，按下即后台静默瞬发。
2. 按 `⌥Space` 输入「左半屏」「下一屏」或你保存的工作区名称（如「编程双屏」），回车即可完成排版并弹出液态玻璃 HUD 轻反馈。
