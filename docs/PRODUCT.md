# 产品定位与边界

## 产品定位

**流光 `Lumakey`** 是一款面向 Apple Silicon Mac 用户的**菜单栏常驻、全局热键驱动的原生快捷效率中枢**：
- 在**主入口形态**上，应用以 `LSUIElement` 驻留于右上角菜单栏（支持 macOS 原生 `SMAppService` 登录项开机自启、静默驻留状态栏、4 款菜单栏图标样式与多显示器唤起定位策略），任何桌面或全屏应用之上按下 `⌥Space`（全部 10 项核心全局热键与扩展插件热键支持可视化录制自定义与三层冲突检测）即可唤起连续曲率大圆角、支持「凝霜留白」与「霓彩流光」双主题实时切换的悬浮控制面板；
- 在**单一全搜中枢**上，通过统一搜索框 + `Tab` 轻量过滤胶囊（`全部` / `文件` / `剪贴板` / `插件`）与 `⌘1..9` / `⌘C` / `⌘Return` 全键盘流，一次性并发检索按使用频率/时长智能排序与常驻钉选的本地化拼音应用、数学与进制/单位换算、内置离线开发工具箱（时间戳/Base64/URL/JWT/JSON/UUID/哈希/色值/二维码）、独立快捷脚本库（`!` 触发词或名称检索，支持 Zsh/Python/AppleScript/Swift/自定义 Shebang 与专属 SVG 图标）、动态快捷短语（`;` 前缀）、端口检测、全盘与外置磁盘文件（免前缀）、剪贴板历史、内置鼠标滚轮/监控命令与扩展插件子功能；
- 在**原生捕获与独立媒体窗口**上，提供逐屏原生 DPI 选区截图标注/离线 OCR/1:1 原位钉屏 (`⌥A` / `⌥O`)、零 `ffmpeg` 原生 `SCStream` 区域 GIF 动图流式录制 (`⌥G`)，以及零 `WKWebView` 的纯原生 Markdown/代码阅读器、只读看图窗与影院视频播放器，支持 **图片/视频窗口置顶、`520×300` 小窗浮层与同目录视频播放列表连播**，关闭窗口即刻销毁内存；
- 在**系统效率内置插件、自定义菜单栏、云备份与扩展生态**上，支持 **顶部状态栏菜单自由定制**（提供「精简核心 / 效率常用 / 完整全量」三套预设、逐项显隐与上下排序、低频维护收纳二级子菜单、无活跃窗口时自动隐藏清理项，以及实时同步自定义热键与开关 `✓` 勾选态），内置独立区分物理鼠标与触控板的 **鼠标平滑滚动与滚轮反转服务**、**系统脉搏监控悬浮窗 (`⌥M`)**、**内置网络流量与去向监控 (`⌥N`)**、**独立应用缓存管理**、**SHA-256 + `LZFSE` 本地加密备份与 `LMKYVLT2` + WebDAV 云端同步**，以及支持 **Plugin v3.7** 独立设置页、按需快捷按钮与菜单栏挂载、结构化卡片实时悬浮面板 (`lumakey://panel/<id>`)、沙盒化自由 `WKWebView` 透明悬浮挂件 (`window` / `floatingWindow`，自动记忆坐标尺寸并实时推送主题/语言/权限变更)、宿主统一代申系统 TCC、跨商店一键检查更新与权限差异确认、`FSEvents` 热重载与内置 `lumakey-mcp` 服务器。
- 在**文件与外置磁盘工作台 (`⌥E`)**上，定位为按需打开、关闭即卸载的**附加工具**，支持列表/网格/紧凑多视图、`⌘`/区间多选与鼠标拖动框选（Marquee）、跨栏拖拽移动/复制、新建文件夹、单文件与批量重命名预检、系统废纸篓安全删除、多字段排序、媒体类型筛选、右侧居中图片/视频实时预览与外置 NTFS 只读护航。
- 所有可选桌面悬浮窗、菜单栏实时读数与插件快捷按钮在**刚安装时默认关闭**，可在设置中心按需自由开启。

## 核心使用场景

1. **可定制模块化启动页、多场景 Profile 与统一全搜一步直达**：空状态呈现支持用户就地编辑与 `lumakey-mcp` 智能编排的模块化启动页（`HomeLayoutConfig` / `home-layout.json`，自动随 `.lumakeybackup` 与 WebDAV 同步）——包含 `2/3/4` 列 Bento 大磁贴、支持本机应用/自制插件/网页书签/目录混排的 `8/16` 格混合高频坞、多组命名书签与插件胶囊架以及可隐藏探索提示条，并支持创建多套场景 Profile 与一键切换 4 套官方预设；输入文字即可同时命中应用、文件名、剪贴板条目、开发工具、短语、数学/换算、端口占用、插件子功能与系统命令。
2. **内置物理鼠标平滑与滚轮反转**：自动识别物理鼠标滚轮并保留触控板自然滚动，支持 120Hz 高帧率平滑滚动、`⇧` 横向、应用排除与搜索关键词秒切换。
3. **Markdown / 代码 / 图片 / 视频独立窗口打开**：选中 `.md`、代码文件、图片或视频，回车或点击侧边预览镜「独立窗口打开」，即可在原生排版与大纲窗口中流畅阅读、切换同级文件。
4. **空闲自洁与最优内存架构**：浮窗隐藏 30s 销毁、索引空闲 90s 或内存告警自动卸载、子进程超限即杀、独立窗口关闭即释放 `contentView` 与堆页。
5. **智能选区截图标注、取色、OCR 与原位钉屏 (`⌥A` / `⌥O`)**：支持冻屏窗口吸附、像素放大镜取色（`C` 键复制 `#HEX`）、矩形/椭圆/箭头/画笔/荧光笔/马赛克/序号/文字实时标注、离线 OCR、前景抠图及选区原位钉图置顶。
6. **外置 NTFS 与文件工作台（附加工具 `⌥E`）**：按需呼出独立双栏窗口，安全识别只读 NTFS 卷并提供批量重命名预检，关闭窗口后立即回收工作台内存。

## 明确的产品边界（不做清单）

为保持产品轻量、专注与 Clean Code 可维护性，`Lumakey` 明确**不做**以下功能：
- **不把主窗做成重型文件管理器**：快捷工具中枢是第一入口，双栏文件管理仅作为按需唤起的附加工作台。
- **不拆分孤立多套搜索框**：所有高频检索收敛到同一主输入流，通过轻量过滤胶囊聚焦范围。
- **不引入 WebKit / 浏览器内核渲染内置文档**：拒绝为内置 Markdown 预览拉起数百 MB 的 `WKWebView` XPC 进程（仅在外部插件显式申请并获授权 `window` / `floatingWindow` 时为其宿主托管按需自由窗口，且关窗即销毁视图实例）。
- **不做图像编辑与视频剪辑**：仅提供无损只读看图与高效播放体验。
- **不做跨平台 / x86_64 兼容**：仅支持 `macOS 14.0+` 与 `arm64`。
- **不做无确认的后台常驻建库服务或冒险强写 NTFS**：不安装 `launchd` 守护进程，不绕过脏标记强行写挂载 NTFS 卷。
